# Geronimo

Geronimo is an inbox app for Gmail and Outlook. It summarizes emails so you can skim your inbox and clear it faster.

## Status

Early setup. No application code yet.

## Stack

Go backend with an HTMX front end. See [docs/system/stack.md](docs/system/stack.md).
